مركز المستقبل التقنيإدارة تحديثات GitHub Pages

تحديث الكتالوج من جهاز الإدارة

هذه نسخة النشر على GitHub Pages. تُجهّز التعديلات من لوحة التحكم في نسخة الإدارة المحفوظة على جهاز المسؤول.

  1. شغّل START-WINDOWS.bat من مجلد نسخة الإدارة وسجّل دخولك.
  2. عدّل المنتجات والصور والأسعار ثم احفظ التعديلات.
  3. اختر «تجهيز نسخة GitHub» لتنزيل ملفات النشر المحدّثة.
  4. فك الملف وارفع محتوياته إلى مستودع الموقع على GitHub.

يظهر التحديث للزوار بعد رفع الملفات واكتمال نشر GitHub Pages.
