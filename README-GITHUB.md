# نشر الموقع على GitHub Pages

فك ضغط الملف وارفع محتوياته مباشرة إلى مجلد نشر الموقع، بحيث يكون index.html في جذر المستودع.

من Settings ثم Pages اختر Deploy from a branch ثم main و/(root) واضغط Save.

رابط النشر المضبوط: https://hassangoap.github.io/future-tech-center/

للتحديثات افتح لوحة التحكم من نسخة الإدارة على جهازك، احفظ التعديلات ثم اضغط تجهيز نسخة GitHub وارفع محتويات الملف الجديد. الصور المرفوعة الموجودة على جهاز الإدارة تدخل في نسخة النشر تلقائيًا. لا ترفع مجلد .data أو حساب المدير أو ملفات خادم الإدارة إلى مستودع النشر.
